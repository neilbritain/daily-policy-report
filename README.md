# 数据和信息化政策日报 Skill

## 功能概述

这个 skill 自动收集世界范围内（重点中国）各级政府部门出台的数据、信息化、算力相关政策，并生成专业的 Word 格式日报。

## 核心特性

✅ **实时政策收集** - 通过网络搜索获取最新的政策信息  
✅ **多时间维度** - 分别呈现 24 小时、一个月、季度的政策动向  
✅ **趋势分析** - 基于政策数据预判 3-6 个月的发展方向  
✅ **专业报告** - 生成格式规范的 Word 文档，约 1000 字  
✅ **机构分类** - 按国务院、部委、省市等级别分类  
✅ **政策标注** - 每条政策标注来源、发布机构、发布日期  

## 使用场景

- **每日定时生成** - 早上 6 点自动生成当日政策报告
- **按需手动生成** - 用户随时请求最新的政策简报
- **专项分析** - 针对特定政策领域的深度分析
- **数据管理** - 形成政策动向档案库

## 重点关注范围

### 政府层级
- 🏛️ 国务院（最高优先级）
- 📋 各部委（工信部、网信办、发改委等）
- 🏢 省市（辽宁、江苏、上海、广东及其他）

### 政策类型（包括但不限于）
- 📊 数据管理 - 数据安全、数据流通、数据治理
- 💻 信息化建设 - 数字政府、信息基础设施
- ⚡ 算力基础设施 - 算力调度、数据中心、芯片
- 🌐 网络相关 - 5G、物联网、边缘计算
- 🔒 网络安全 - 信息安全、隐私保护、基础设施保护
- 🤖 AI 相关 - 生成式 AI 监管、算法治理

## 工作流程

```
1. 接收请求
   ↓
2. 网络搜索收集政策信息（多关键词、多时间维度）
   ↓
3. 筛选和验证（官方来源优先）
   ↓
4. 按机构等级和政策类型分类
   ↓
5. 组织内容（24小时、一个月、季度、趋势）
   ↓
6. 生成 Word 文档
   ↓
7. 输出报告
```

## 网络搜索策略

为了获得最精准的政策信息，该 skill 使用以下搜索策略：

### 24 小时政策搜索
```
"国务院" "最新政策" "2026年5月17日"
"工信部" "部委" "政策发布" 今天
"[省市名]" "政府" "通知" "2026年5月"
```

### 一个月政策搜索
```
"政策发布" "数据管理" "信息化" "2026年4月-5月"
"[机构名]" "公告" "新规" "过去30天"
"[省市名]" "政策" "信息化" "最近一个月"
```

### 季度政策搜索
```
"政策框架" "发展规划" "2026年Q1 Q2"
"数据战略" "信息化建设" "季度"

```

## 技术实现

### 依赖项
- Web 搜索 API（获取实时政策信息）
- Python docx 库（生成 Word 文档）
- 日期时间处理库（时间计算和比对）

### 执行流程
1. 接收用户请求并解析时间参数
2. 构建多个搜索查询（覆盖不同机构、时间维度、政策类型）
3. 执行网络搜索并收集结果
4. 解析搜索结果，提取关键信息
5. 验证来源的官方性和权威性
6. 按重要性和时间排序政策
7. 组织内容并生成 Word 文档
8. 输出最终报告

## 常见问题

### Q: 如何保证信息准确性？
A: 该 skill 优先使用官方网站（gov.cn 等）和权威媒体的信息，对每条政策进行来源验证。

### Q: 能否针对特定领域生成报告？
A: 可以。用户可以指定关注的政策领域（如"仅关注算力"或"仅关注网络安全"）。

### Q: 报告何时生成？
A: 支持两种模式：
- 定时生成：每天早上 6 点自动生成
- 按需生成：用户随时请求即可生成最新报告

### Q: 如果某个时间段没有新政策怎么办？
A: 该 skill 会如实说明信息状况，并可以自动扩大搜索范围或提供相关历史政策作为参考。
